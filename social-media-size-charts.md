## 🔤 File Format Quick Reference

| Format | Best For | Notes |
|---|---|---|
| JPG / JPEG | Photos, complex images | Smaller file size; lossy compression |
| PNG | Graphics with transparency, logos, icons | Lossless; larger file size |
| GIF | Short animations | Limited to 256 colours |
| MP4 | Videos | H.264 codec recommended across all platforms |
| MOV | High-quality video | Apple format; widely supported |
| WebP | Web-optimised images | Smaller than PNG/JPG; broad browser support |
| SVG | Scalable vector graphics, logos | Infinitely scalable; not supported in most social uploads |
| PDF | Documents, carousels (LinkedIn) | |

## 📝 Notes

- **Safe Zones**: Always keep primary content (text, logos) within the central safe zone to prevent cropping on different devices.
- **Retina / High-DPI**: Export assets at 2× recommended dimensions for crisp display on high-density screens.
- **File Size Limits**: Most platforms cap uploads at 8–30 MB for images and 500 MB–4 GB for videos; check platform-specific limits before uploading.
- **Colour Space**: Use **sRGB** for all digital assets to ensure consistent colours across screens.
- Dimensions and limits are subject to change — always verify against the latest official platform documentation.
